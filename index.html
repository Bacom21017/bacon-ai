Cloud PC: use your iPad with the laptop off

A cloud PC runs the controller, Ollama, project files and coding tools. Chatting and general coding do not require Roblox Studio.

  1. Create or use your own always-on Linux machine. Hosting and GPU costs are separate from ChatGPT.
  2. Follow docs/CLOUD-PC.md and run deploy/Setup-Cloud-PC.sh there.
  3. Complete your official ChatGPT/Codex device sign-in and private Tailscale setup.
  4. Open its private HTTPS address on your iPad and enter that host’s pairing token.

Use that same address on all your devices. One cloud controller owns your projects, so switching devices does not require moving files or prompts. This app does not purchase hosting or pretend a cloud PC already exists.

Private device access

  1. Install Tailscale on your controller host and Apple device. Sign into your own private network.
  2. For a laptop controller run Enable-Remote.cmd; for a cloud PC use its setup script.
  3. Open the printed HTTPS address in Safari with Tailscale connected.
  4. Tap Share → Add to Home Screen.

A laptop-hosted controller requires the laptop to stay awake. A cloud-PC controller requires only the cloud PC to stay online. Public Funnel is not enabled.

Windows app

Run Install-Desktop.cmd for a shortcut or Build-Windows.cmd to package the local app. Cloud deployment does not require the Windows app.

Real cloud hosting, Windows packaging and Apple installation require deployment/device testing.

A quick start, with Bacon.

  1. Install Python, Ollama and the official Codex CLI, then run Setup.cmd.
  2. Sign into Codex with your ChatGPT account. Run Start.cmd and connect using its token.
  3. Create a project, describe the outcome, and press Start.
  4. Approve a build/test tool when requested. Generated code runs under your user account, not an OS sandbox.

Cloud access uses your supported Codex subscription session by default. API billing is a separate explicit setup choice; Bacon AI never silently switches to it.

Roblox: install the existing plugin using Install-Plugin.cmd. Keep one bridge active in a blank Studio place. Generated place files are downloadable from completed Roblox tasks.

UEFN/Verse compilation and game-specific testing still take place in their official editors. View exact capability status in Control center.

The original Roblox builder is available at /legacy on your controller.
